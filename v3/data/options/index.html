Options Page :: Always active Window

Event blocking options (these options apply to enabled websites)

Extra Options

List of Hostnames

List of hostnames where the extension is active, separated by commas. You can modify this list by clicking the action button to add or remove hostnames. Enabling the extension on all hostnames with "*" is possible but discouraged, as it may negatively impact performance. Instead, limit the extension's use to hostnames that require an active tab to function properly. Example: example.com, *.example.com, www.example.com

Policies

A JSON object to prevent blocking of some events that conflict with particular hostnames. Example: {"docs.google.com": ["blur"]}
